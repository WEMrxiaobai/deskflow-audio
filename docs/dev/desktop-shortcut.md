# 1.27.6 桌面快捷方式修复

1.27.5 安装包只在开始菜单创建应用和说明入口，没有声明桌面入口。本版在 MSI 标准 `DesktopFolder` 下增加 `Deskflow` 快捷方式，直接指向安装目录的 `deskflow.exe`，工作目录为安装目录。

桌面入口复用现有快捷方式组件和功能引用，并使用 HKCU 注册表 KeyPath，使安装、升级、修复和卸载继续由 Windows Installer 管理。卸载只删除本组件登记的快捷方式，不删除桌面目录；开始菜单入口保留。

安装包校验读取编译后的 MSI 数据库，检查桌面位置、GUI 目标、工作目录、组件所属功能、注册表 KeyPath，以及 CreateShortcuts/RemoveShortcuts 标准动作。WiX 编译、链接及 ICE 校验后，再核对 CAB 内实际文件和独立依赖启动。

本版仅修改安装包配置，应用二进制沿用 1.27.5。未在当前双机上自动安装或卸载，桌面图标实际显示仍需安装后确认。
